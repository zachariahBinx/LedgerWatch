# LedgerWatch

## Summary
Project purpose is to build a spin off of enterprise budget tracking applications such as Rocket Money or Monarch Money. Features will not be as riched and data input is static (requiring certain .csv columns), but it's free and personable. Project is design to help learn full stack skills and track monthly budget spendings.

## Arcitechture
Python backend
Local sqlite3 local database
Javascript - React frontend
